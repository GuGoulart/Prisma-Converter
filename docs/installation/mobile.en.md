# Complete Mobile (PWA) Installation Guide — Android & iPhone (iOS)

**Prisma Converter** is engineered as a full commercial-grade **Progressive Web App (PWA)**, allowing native-like installation on Android and iOS devices without requiring app stores.

---

## 📱 1. Android Installation (Chrome / Edge / Samsung Internet)

1. **Open Browser:** Navigate to your Prisma deployment URL (e.g. `https://prisma-vmbr.onrender.com`).
2. **Install Prompt:** Tap **"Add to Home screen"** or **"Install App"** when prompted.
3. **Manual Install:** Tap browser menu **(⋮)** -> Select **"Install app"** or **"Add to Home screen"**.

---

## 🍎 2. iPhone / iPad Installation (Safari)

1. **Open Safari:** Navigate to the web app URL inside Apple Safari.
2. **Share Menu:** Tap the **Share button** (square with upward arrow).
3. **Add to Home Screen:** Scroll down and tap **"Add to Home Screen"** -> Tap **"Add"**.
4. **Launch:** Tap the Prisma icon on your iOS home screen for full-screen PWA execution.
